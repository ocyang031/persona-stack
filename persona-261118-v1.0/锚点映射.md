## 命名与维护约定

1. **格式**：全大写 + 下划线，前缀分组 `IDENTITY_` / `SOUL_` / `DELIVER_` / `ROUTE_` / `HONESTY_` / `SESSION_` / `TOOLS_` / `DOMAIN_`。
2. **一锚点一条款**：只绑一条可验证行为；禁止纯形容词锚点。
3. **行内放置**：随 `persona.py compile` 原样进入产物，AI 与人读同一份文本。
4. **文件归属**：气质/事实 → IDENTITY/SOUL；裁决与纪律 → contract；域规格 → domain。
5. **变更流程**：改源文件 → 同步本表 → `persona.yaml` 升版 → 双宿主 install 重验。
6. **剥离项不设锚点**：muse 的护栏覆写段落（见映射文档 §B）不进源、不编译、不注入。
