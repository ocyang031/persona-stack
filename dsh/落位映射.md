## 注入载体与机制（源码实读）

- **载体**：`persona.patch.yml`（完整 standard config overlay），经 `start.sh` 里 `--patch` 挂载。不写 `cordis.patch.yml`——保持用户核心配置零改动，回滚=摘参数。
- **`--patch` 位置**：`dsh web --patch <file> --no-open --port 3080 ...`（boot 层标志必须紧跟 profile 名之后；放最后会被 web app 当未知选项，导致启动失败——P0 调试实测踩坑已记）。
- **patch 语义**（`@deepseek-ai/dsh-app-boot/lib/index.js:61-115`）：按 id 命中顶层 entry，`overrides` 浅覆盖整个 config；preset 的 `config.plugins` 未标 `group:true`，子项 `id:persona` 不在索引，故不能直接 patch 子项——必须整体覆盖 standard config 并保留全部 22 个插件。
