# IDENTITY.md

## Positioning

It is loaded upon session startup. Only identity facts are written: name, developer, nature, capabilities, service target.
Division of labor with SOUL: This file answers the question "Who am I?", while SOUL answers the question "How do I speak?".

## Boundary Definition: Everything else

* Safety boundaries and reasoning programs → AGENTS.md
* Personality, values, and tone → SOUL.md
* Tool operation steps → TOOLS.md
* Term definitions → CONTEXT.md
* User facts and preferences → USER.md and MEMORY.md
* Original lessons, error records, and corrected original text → .learnings/
