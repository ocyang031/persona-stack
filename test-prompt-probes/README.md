# AGENTS 探针对照准备

先审计 PROBES.md。它只包含探针编号、Full 章节和原始题面。多轮题每个引用块是一轮。离线检查用 python -B -X utf8 run.py check。正式运行需要由操作者在审计后明确允许，并把检查输出的 SHA256 交给 run 子命令的 --approved-sha256。文件改动会使旧哈希失效。

三组为裸臂、极简快照 aed40828ab97718e 和 Full 快照 b08ee5f92df2eaed。以同一模型 home-magpie/meoo/deepseek-v4.1-flash-1017 和 low 档位运行。使用本机 DSH TUI 0.19.0 的兼容 core 0.2.2-rc.1。每题的三组轮换顺序，上一组收尾并核对后才开始下一组。每组单独启动 TUI 实例，使用新工作区、配置、偏好文件和会话目录。唯一的多轮题在同一组会话内完成。超时、错注入、模型不匹配、会话重复、工具或原生提示变化时停跑保留现场。

所有运行目录位于 runs 下。各组用临时 overlay 注入，正式 DSH profile 和绑定文件只读取。收尾关闭本次进程并比较正式配置、偏好和在用前缀的哈希。如果原配置被外部改变，记录差异并停跑，避免用旧副本覆盖其他改动。套件目录包含全部合成工作夹具。Windows TUI 的临时工作区隔离实验数据，工具权限仍取决于实际宿主配置。

每次运行只产生一份统一结果文档 runs/<run-id>/evidence.json，内含模型、题面、随机样本编号、原始可见答复、会话事件、工具记录、每个请求的最终模型上下文、文件快照和恢复核对。上下文由 TUI 的 /debug-prompt 捕获。异常终止前未取得完整上下文时保留会话现有事件，并明确标记缺失。日志按阶段原子更新。环境凭证不写进结果文档。

盲评前用 python -B -X utf8 run.py blind-view <evidence.json> 查看匿名答复和文件。完整证据里的系统提示可反推出组别，评审阶段只给盲评视图。组别映射另存于 group-key.review-after-scoring.json，评分冻结后再打开。实验目录、证据和运行快照适合留在本机。
