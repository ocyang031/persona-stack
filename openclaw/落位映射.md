## 托管区块三态（install 语义）

标记格式：`<!-- persona:persona-261118-v1.0@<version> BEGIN/END -->`

1. 目标文件不存在 → 整文件写入编译产物；
2. 有本 persona 标记（任意版本）→ 只替换标记之间内容，区块外不动；
3. 无标记 → 产物区块追加到文件尾部，原有内容保留。

## 命令

```
python3 persona.py compile  --host openclaw
python3 persona.py install  --host openclaw --target <workspace目录>
python3 persona.py verify   --host openclaw --target <workspace目录>
python3 persona.py uninstall --host openclaw --target <workspace目录>
```

- 默认 target：`/root/.openclaw/workspace`（沙箱内未部署 OpenClaw，实际落位在用户宿主机执行）
- install 失败自动还原（备份目标原内容 / 删除新建文件）
- uninstall = 删整块，宿主自有内容保留

## 版本指纹与幂等

- 区块内首行为 `<!-- persona:persona-261118-v1.0@v1.2 -->`；源升版 → 重 compile → 重 install，区块整体换新。
- 锚点约定（UPPER_CASE 行内标记）跨 dsh/openclaw 两种格式通用，不依赖宿主。
